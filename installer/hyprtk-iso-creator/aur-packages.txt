# AUR packages baked into the live ISO.
#
# Built on the *host* at ISO-build time (as the invoking user, never root) with
# `makepkg --nodeps`, then installed into the chroot by customize_airootfs.sh.
# The build is best-effort and non-fatal: anything that fails to build is
# reported and simply left out — the ISO still gets produced.
#
# `--nodeps` means the host must already have each package's makedepends
# (base-devel plus e.g. meson/wayland headers for swaylock-effects). Run the
# builder with --no-aur to skip this stage entirely.
#
# One package per line. Blank lines and lines starting with # are ignored.
